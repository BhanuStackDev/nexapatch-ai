# NexaPatch Sample Workspace

This is a small, sanitized Python project intended for repository-inspection demos.

It contains no credentials, personal records, or private repositories.

## Inspection exercise

The discount calculation handles ordinary percentages but does not validate
negative prices or discounts outside the 0–100 range. The tests cover only
basic valid inputs. Review the edge cases and recommend additional tests.

NexaPatch should inspect this workspace in read-only mode.
